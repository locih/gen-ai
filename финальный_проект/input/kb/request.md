# Runbook: Запрос на обслуживание

## Охват
Консультации, стандартные изменения, запрос оборудования, тестирование.

## Шаги L1
1. Уточнить цель запроса и срок.
2. Проверить, есть ли типовая услуга в каталоге ServiceDesk.
3. Для оборудования: указать модель, количество, обоснование, согласование руководителя.
4. Для тестирования: описать стенд, версию, окно работ.

## Эскалация
- Линия по типу услуги из каталога.

## SLA
Стандартный запрос — 2 рабочих дня.
