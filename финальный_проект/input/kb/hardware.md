# Runbook: Оборудование

## Охват
Компьютеры, мониторы, телефоны, принтеры/МФУ, картриджи.

## Шаги L1
1. Перезагрузить устройство и проверить кабели (питание, сеть, USB).
2. Для принтера: проверить очередь печати, статус «Offline», замятие, уровень тонера.
3. Для МФУ: устранить замятие по инструкции на устройстве, перезапустить spooler печати на ПК.
4. Для телефона: проверить регистрацию на АТС, переподключить кабель.
5. Зафиксировать инвентарный номер и адрес кабинета.

## Эскалация
- Группа «Рабочие места» — замена/ремонт ПК и телефонов.
- Группа «Печать» — МФУ, картриджи, сложные сбои печати.

## SLA
Полный простой рабочего места — реакция 1 ч.
