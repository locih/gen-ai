# Runbook: Учётные записи

## Охват
Создание/блокировка учётных записей, восстановление доступа новых сотрудников.

## Шаги L1
1. Проверить статус сотрудника (активен/уволен/ перевод).
2. Для нового сотрудника: убедиться, что HR завёл карточку и есть заявка от руководителя.
3. Для восстановления: проверить блокировку AD, инициировать сброс пароля через IDM/ServiceDesk.
4. Никогда не сообщать пароль по телефону — только через защищённый канал.

## Эскалация
- Группа «IAM / AD» — создание, блокировка, группы.

## SLA
Новый сотрудник — доступ в первый рабочий день.
