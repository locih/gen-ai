# Runbook: Программное обеспечение

## Охват
Установка ПО, TrueConf, CryptoPro, САПР, модули согласования, АС Договор.

## Шаги L1
1. Уточнить название ПО, версию, ОС, текст ошибки и скриншот.
2. Проверить, есть ли ПО в реестре разрешённого ПО.
3. Для установки: создать заявку с обоснованием; установка через SCCM/скрипт L2.
4. Для CryptoPro/ЭП: проверить срок сертификата, установлен ли CSP, права на USB-токен.
5. Для ошибок БД/АС Договор: зафиксировать время, запрос SQL/код ошибки; не перезапускать сервис без L2.

## Эскалация
- Группа «ПО и лицензии» — установка, обновления.
- Группа «Прикладные системы» — 1С, АС Договор, САПР.

## SLA
Установка стандартного ПО — 1 рабочий день.
