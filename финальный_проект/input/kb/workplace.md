# Runbook: Рабочее место

## Охват
Перемещение АРМ, настройка нового места, сдача оборудования на склад.

## Шаги L1
1. Зафиксировать адрес, кабинет, дату переезда, список оборудования.
2. Согласовать с руководителем и службой эксплуатации помещения.
3. Для нового АРМ: проверить наличие сетевой розетки, порта, места на столе.
4. Для сдачи оборудования: составить акт, передать на склад, снять с учёта.

## Эскалация
- Группа «Рабочие места и логистика».

## SLA
Переезд АРМ — планирование 3 рабочих дня.
