# Runbook: Доступы и учётные системы

## Типовые системы
СДО (система документооборота), МОСЭДО, VDI, Oracle, 1С, сетевые папки, disk.mggt.ru.

## Шаги L1
1. Уточнить ФИО, подразделение, название системы и текст ошибки.
2. Проверить, не истёк ли пароль и не заблокирована ли учётная запись (AD).
3. Для СДО/МОСЭДО: попросить пользователя выйти, очистить кэш браузера, зайти снова через корпоративный VPN.
4. Для VDI: перезапустить клиент Horizon/VDI, проверить сеть.
5. Для Oracle/1С: проверить роль в заявке; если роли нет — оформить заявку на доступ с согласованием владельца системы.
6. Для сетевых папок: проверить группу безопасности и путь UNC.

## Эскалация
- Группа «Доступы и IAM» — новые права, Oracle, 1С.
- Группа «СДО/МОСЭДО» — документооборот.
- Группа «VDI» — виртуальные рабочие столы.

## SLA
Критичный простой ключевой системы — реакция 30 мин, решение 4 ч.
