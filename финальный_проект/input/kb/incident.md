# Runbook: Инцидент

## Охват
Незапланированное прерывание ИТ-услуги, массовый сбой.

## Шаги L1
1. Зафиксировать время начала, масштаб (один пользователь / отдел / все).
2. Проверить статус на странице инцидентов / канале ops.
3. Если массовый — эскалировать немедленно, не пытаться «лечить» локально.
4. Сообщить пользователю номер инцидента и ожидаемое время обновления.

## Эскалация
- Дежурный L2 / Incident Manager — немедленно.

## SLA
Критичный инцидент — реакция 15 мин.
